
# Moodboard – Lapuan Lepakot ry

## 1. Feeling

- Warm – The beige and brown colours create a warm and traditional feeling.
- Welcoming – The website should make new players and families feel welcome.
- Clear – Visitors should easily find matches, training times and registration information.

## 2. Colours

### Light Mode

| Name | Hex | Used for |
|---|---|---|
| Beige | #f3ead8 | Main background |
| Dark Brown | #2e2a24 | Text, header and footer |
| Brown | #8a5a2b | Headings, buttons and links |
| Cream | #fff8ee | Cards and sections |
| White | #ffffff | Button text |

### Dark Mode

| Name | Hex | Used for |
|---|---|---|
| Dark Brown | #211e19 | Main background |
| Light Beige | #f3ead8 | Main text |
| Light Brown | #d6a66e | Headings, buttons and links |
| Brown Grey | #302a23 | Cards and sections |
| Almost Black | #171410 | Header and footer |

The beige and brown colours follow the client's preferred
colour palette and give the website an old-paper appearance.

### Colour Contrast

| Colour combination | Contrast ratio |
|---|---|
| Light mode text and background | 11.93:1 |
| Dark mode text and background | 13.90:1 |
| Light mode accent and background | 4.91:1 |
| Dark mode accent and background | 7.54:1 |

These colour combinations meet the minimum WCAG
contrast requirement of 4.5:1 for normal text.

## 3. Fonts

### Headings – Georgia

Georgia gives the website a traditional and friendly
appearance that matches the club's colour palette.

### Body Text – Arial

Arial is simple, clean and easy to read on both
mobile phones and computers.

## 5. Logo

The website uses a simple text-based logo with
the club name, Lapuan Lepakot ry, and the subtitle
Floorball Club · Lapua.

The logo matches the traditional colour palette
and also works as a link to the home page.

## 6. Layout

The website uses a simple and responsive layout.

CSS Grid is used for cards and content sections,
while Flexbox is used for navigation.

On mobile devices, the content is arranged vertically.
On larger screens, sections can appear side by side.

## 7. Accessibility

The design includes:

- Readable fonts
- High colour contrast
- Visible keyboard focus
- Responsive layouts
- Automatic dark mode
- Clear navigation and form labels

The goal is to make the website easy to use
for players, parents and other visitors.
