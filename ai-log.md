
# AI Usage Log – Lapuan Lepakot Website

## Exercise E1 – HTML and Website Planning

### 1. Understanding the Client's Requirements

I used AI to get help understanding the client's brief
and the main requirements of the website. It helped me
understand what information should be included for
players, parents and new members.

### 2. Website Planning

I got help from ChatGPT when planning the website
pages and organising the content.

### 3. HTML Development

I used ChatGPT to get help with writing HTML code
and understanding headings, navigation menus,
tables and forms.

### 4. Website Content

I got suggestions for organising the content on the
home, about, matches and contact pages.

### 5. Learning and Problem Solving

Whenever I had difficulties with HTML, I asked
ChatGPT for explanations. This helped me understand
how different parts of a website work.

## Exercise E2 – CSS and Responsive Design

### 1. CSS Styling

I used ChatGPT to get help with writing CSS and
improving the overall appearance of the website.

### 2. Responsive Design

I got help with using Flexbox, CSS Grid and media
queries to make the website suitable for different
screen sizes.

### 3. Colours and Dark Mode

I received suggestions for colour combinations,
fonts and implementing dark mode while following
the client's preferred colour palette.

### 4. Moodboard

I used AI to get help organising the moodboard
and explaining the design choices.

### 5. Testing and Problem Solving

While testing the website on a smaller screen,
I noticed that the navigation menu was displayed
in two lines. I got help from ChatGPT to fix this
problem.

### 6. What I Learned

During E2, I learned more about CSS variables,
Flexbox, Grid, media queries and dark mode.
I also learned how to use browser developer tools
to check the website on different screen sizes.
